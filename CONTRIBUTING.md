# Contributing to LogisticsLab Studio

Contributions are welcome: bug reports, suggestions and pull requests.

## Bugs and suggestions

Please open an issue on GitHub. For bugs, the version, the platform (macOS, Windows, Linux, web, tablet), the scenario file and a screenshot help.

## Pull requests

- Before larger changes, please open an issue first so we can agree on the approach.
- Code and comments follow the style of the surrounding files.
- `flutter analyze` and `flutter test` must pass.
