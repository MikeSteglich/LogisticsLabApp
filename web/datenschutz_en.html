Privacy policy for LogisticsLab Studio

LogisticsLab Studio is a web application of Technische Hochschule Wildau for teaching and learning in logistics: it calculates transportation, location, routing and network problems. The application is designed so that only the personal data required for its operation are processed. There are no user accounts, no tracking and no analytics or advertising services.

4. Accessing the web application and server log files

When the web application is accessed and with every request to the calculation server, the web server processes the following data for technical reasons:

  • IP address
  • date and time of access
  • requested address (URL), status code and amount of data transferred
  • browser and operating system (user agent) and the previously visited page (referrer), if transmitted

Purpose: delivery of the application, security and stability of operation (including limiting requests per IP address against overload), error analysis.

Retention period: The log data are stored in server log files and automatically deleted after 14 days.

Legal basis: Art. 6(1)(e) GDPR in conjunction with the tasks of the university in teaching and research; where necessary Art. 6(1)(f) GDPR (secure and stable operation).

5. Calculations

For a calculation, the application sends the edited scenario to the calculation server: locations with their coordinates and, where applicable, addresses, quantities, capacities, costs and the settings of the problem. These data are used exclusively for the calculation.

  • The scenario and the result are held only in the main memory of the server. Collected and uncollected results are deleted after one hour at the latest.
  • Technical logs of the calculations (time, problem type, computing time, error messages) are stored for error analysis and rotated regularly.
  • Calculated distances and travel times between coordinates are kept in a cache for up to 180 days so that they do not have to be requested again. They are not assigned to any person.

Please do not enter personal data in scenarios, in particular no names or private addresses of persons. For teaching, places, companies or fictitious data are sufficient.

Legal basis: Art. 6(1)(e) GDPR (teaching and learning offering of the university).

6. Distances, travel times and address search (OpenStreetMap services)

For distances and travel times on the road network, the course of routes and the search for addresses (geocoding), the calculation server – not your browser – queries coordinates or the entered address from the following services:

  • routing and geocoding servers based on OpenStreetMap operated by Technische Hochschule Wildau,
  • alternatively Photon of komoot GmbH (photon.komoot.io), Potsdam, Germany,
  • alternatively Nominatim of the OpenStreetMap Foundation (nominatim.openstreetmap.org), United Kingdom.

Only the coordinates or the search text are transmitted, not your IP address or other information about you. An adequacy decision of the European Commission exists for the United Kingdom (Art. 45 GDPR).

Legal basis: Art. 6(1)(e) GDPR.

7. Map display (OpenStreetMap)

The background map consists of map tiles that your browser loads directly from the tile server of the OpenStreetMap Foundation (tile.openstreetmap.org, St John’s Innovation Centre, Cowley Road, Cambridge, CB4 0WS, United Kingdom). In doing so, your IP address, the requested tiles (and thus the displayed map section), date and time and your user agent are transmitted to the OpenStreetMap Foundation.

An adequacy decision of the European Commission exists for the United Kingdom (Art. 45 GDPR). The OpenStreetMap Foundation processes the data under its own responsibility, see its privacy policy: osmfoundation.org/wiki/Privacy_Policy.

Legal basis: Art. 6(1)(e) GDPR; the map is required for working with the application.

8. Storage in the browser

The application stores your settings in the local storage of your browser: language, layout of the view, the address of the calculation server and, where applicable, your API key. These data remain in your browser and are not evaluated. No cookies are set.

The storage is strictly necessary for the use you requested (§ 25(2) no. 2 TDDDG). You can delete the data at any time via the settings of your browser.

9. API keys

Access to the calculation server may be protected by API keys issued by the university, for example for a course. For a key, the server stores only a check value (hash), a name, an expiry date and usage limits, not the key itself.

10. No integration of further third parties

Program parts and fonts of the application are loaded from our own server. No content from Google or other third-party providers is integrated – with the exception of the map tiles described in section 7.

11. Automated decision-making

No automated decision-making including profiling (Art. 22 GDPR) takes place.
